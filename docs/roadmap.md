# 路线图

目标:完整逆向 DNF 客户端,用 Unity 6 LTS 重新实现,在 Windows、macOS、Android、iOS 上运行,运行时读取用户自备的原版数据。

完成标准:用用户自备数据在 Unity 里跑通"登录 → 选角 → 进城 → 进副本 → 击杀 → 结算",四个平台各验证一次;P2 的 tag 覆盖率与差分测试通过率有记录;每条被实现的规则都能追溯到证据或差分测试。

|---|---|---|---|---|

## 前置条件(需要用户确认再做)

- .NET SDK:用户级安装(`~/.dotnet`),不需要管理员权限。
- Unity Hub 与 Unity 6 LTS:10 GB 以上。
- iOS 构建需要完整 Xcode(本机只有 Command Line Tools);Windows 构建需要一台 Windows 机器或 CI;Android 与 iOS 需要真机验证。
- 在 Wine 里运行原版客户端录制对照基线:会连接用户的私服,需要用户同意与登录。
