# 副本结算:压暗的场景、营火、德利拉与"是否继续?"菜单(M9a,E-091、E-092)

首领房清空之后,原版画面变成:场景压暗、主角脚下生起一堆营火、修理商德利拉站在火边、右上角出一块"是否继续?"的菜单。
本文只记**布局事实、数据链与规则**;图片本身不入库,运行时从用户自备的 `ImagePacks2` 与 `Script.pvf` 里读。
物品掉落物、名牌、评分、原版结算页上的经验显示没有做(见 §7);打怪得经验与升级已经做了(见 `docs/exp.md`,E-111),金币掉落与拾取也做了(M24,E-116);本次得到的经验与金币现在画在一块自己设计的占位战果小结里(`docs/flow.md` §9),不是原版版式。

证据等级:面板位置与营火/NPC 的数据链是读出来、逐像素验证过的(高);压暗的层次与亮度系数是对基线结算帧做回归量出来的(中);
时机(清空到出菜单隔多久、黑幕淡入多久)、营地的摆放位置是占位或粗测(低),在对应段落里写明。

## 1. 观察(基线 S10 结算连拍,本机、不入库)

- 画面是首领房(洛兰领主房)本身,不是单独的结算场景;主角还站在房间里,在营火的位置上(被火和木柴挡住)。
- 地图图层(远景、中景、近景背景、树桩、地面)整体变暗;**营火的火芯没有变暗**(亮到 255);德利拉比地图图层亮一些;底栏与右上角面板不变暗。
- 右上角是一块面板(标题图案、四行、收边),四行是"再次挑战 / 快速组队 / 选择其它地下城 / 返回城镇",后面三行带热键提示:(F13)、(未指定)、(F11)、(F12)。
- 营火周围散落着掉落物与它们的名牌,主角头顶有名牌,德利拉头顶有名牌——这些都没有做。
- 清空首领到出结算菜单之间,基线有一段 38.5 秒没有拍到(连拍间隔),**真实的时机没有量到**。

## 2. 数据链

| 内容 | 来源 |
|---|---|
| 营火 | 动作脚本 `passiveobject/actionobject/common/action/campfire.act` 的 `[MOTION]`:`[BASE ANI]` 是木柴出现,`[SUB ANI]` 依次是火出现、木柴、火焰循环、光晕,共 5 层,各层偏移都是 (0, 0) |
| 营火各层的画法 | 火出现、火焰、光晕是加法混合(帧属性 11 = 2);木柴与火出现的第一帧带 alpha 0 与"向下一帧插值"(帧属性 9、10),所以是淡入;光晕图在 `sprite/interface/eplp.img`,其余在 `sprite/map/campfire.img`;淡入与循环的时长都取自动画自己的帧 |
| 德利拉 | 首领房地图的 `[NPC]` 列表 → `npc/npc.lst` → `.npc` 带 `[visible on dungeon clear] 1`(全库只有德利拉与三个加百列带它);外观取 `.npc` 的 `[field animation]` |
| 面板 | `sprite/interface/eplpnew.img`:#0 头(268×54)、#1 行(270×30)、#2 脚(268×16);四个选项各 4 张按钮文字图(常态、悬停、按下、禁用),首张帧号 5、9、13、17 |

菜单文字在图里,PVF 里没有文本;热键提示 "(F13)" 在原版里是系统字体渲染的,我们用内置的像素字摆在文字右边。

## 4. 压暗与层次(E-092)

对基线结算帧与我们自己渲染的未压暗房间(同一镜头)做逐通道线性回归(基线 = 系数 × 我们的 + 截距):

- 地图图层(远景、中景、地面、近景背景的树桩)系数都在 **0.61** 附近(0.60 到 0.63),截距 ≈ 0:是乘性的变暗,不是 alpha 混合。
- 德利拉取蓝色通道(加法光晕几乎不加蓝)、只用她离火较远的左半身回归:系数 **0.76 到 0.78**(全身与分段回归 0.74 到 0.84,有噪声);红、绿通道多出的正截距是营火光晕的加法光。
- 火芯的最亮处与基线一样亮到 255:营火在压暗之上,没有被压暗。

**推断(中)**:盖了**两层相同的黑幕**——第一层在地图图层之上、物件(主角、怪物、德利拉)之下,第二层在物件之上、界面之下;营火各层画在第二层之上。
每层黑色 alpha 56(乘 0.780),叠起来乘 0.609,恰好是量到的 0.61 与 0.76 到 0.78 两个数。
物件(主角、怪物)与近景图层([close])是不是各乘 0.78 没有量到(基线里主角被火挡住,近景树干没有对上号)。

实现上的层次(`TownScene.SortByDepth` 的大类,同大类按列表顺序画):

| 大类 | 内容 |
|---|---|
| 0 到 2 | 远景、中景、近景背景 |
| 3(`bottom`) | 地面图层;**第一层黑幕**(`OverlayArt.BackDimRank`)追加在这一类的最后 |
| 4(`normal`) | 主角、怪物、德利拉,按世界 y 排 |
| 5(`close`) | 近景图层 |
| 6(`OverlayArt.DimRank`) | **第二层黑幕**,然后是营火各层(`ClearCamp.FireRank`) |
| 7(`OverlayArt.UiRank`) | 结算面板、小地图、转场黑幕 |

房间场景把外面传进来的精灵(含黑幕、营火、面板)追加在地图图层之后再稳定排序,所以第一层黑幕盖住大类 0 到 3 的全部图层——这条顺序有合成测试守着。

## 5. 实现

- `DungeonSession`:首领清空后 `SettlementDelayMs`(3 秒,**占位**)进入结算(`SettlementActive`);黑幕在 `SettlementDimMs`(0.5 秒,**占位**)里线性淡入到每层 alpha 56;
  结算期间主角照常可操作;小地图与 CLEAR 字样撤掉。选项由 `Choose`(热键)、`Click`(鼠标或触摸)记下,只接受第一次、只接受可用的行(快速组队没有,点了没反应);`SetPointer` 让悬停的行换成悬停图。
  选定之后 `Choice` 不再是 `None`,下一步由外面决定。
- `ClearCamp`:营火生在首领清空时主角的脚下(**观察**:营火原点与主角脚下重合),德利拉站在营火左边约 100 像素、脚线与营火同高(**粗测**,横向 ±5 像素量级:用她的帧镜像后与基线对位,相关系数 0.92;
  营火原点由木柴图位置反推,木柴被火光与名牌遮挡,相关系数只有 0.3)。地图里营地 NPC 的坐标写 (0, 0, 0),原版是运行时安排的位置,**规则没读到**。
  营火各层与德利拉都是常驻动画(`AnimatedEffect.Persistent`:不循环的停在最后一帧、循环的一直循环),所以营火是"生"出来的,德利拉没有出现动画、直接站着。
- `SettlementArt`:面板与四行文字图;图包里取不到时(合成数据测试)退回像素字的占位面板(`BuildFallback`)。
- 播放器(`TownDemo`):F13 再次挑战、F11 选择其它地下城、F12 返回城镇;笔记本键盘没有 F13,所以数字键 1、2、3 也行(**本演示加的,原版没有**);
  鼠标点菜单行或触摸;选定时日志里留一行 `DNF_SETTLE choice=…`;`-dnfafterclear <秒>` 让离屏渲染在清空之后再让时间走这么久(与命令行 `dungeon-check --after-clear` 同一个规则)。
  无人值守的自动机(`-dnfbot`)清空之后站着不动、只让时间走,所以实时运行也会走进结算。

## 6. 推断与占位

- 清空到出菜单的 3 秒、黑幕淡入的 0.5 秒:占位(基线里这段没拍到)。
- 两层黑幕、营火在第二层之上:对三处亮度系数的解释,不是读到的规则;主角、怪物、近景图层的亮度没量。
- 德利拉相对营火的位置、营火在主角脚下:粗测。
- 光晕图帧属性 7(缩放 0.95)没有实现(`AnimatedEffect` 只认缩放的符号),我们的光晕比基线略大略亮(德利拉身上红、绿通道的加法光多 0.07 到 0.09 的量级)。
- "(未指定)" 的提示没画(内置像素字没有汉字);快速组队行永远是禁用图。
- 菜单行的"按下"图没用(点击立即生效)。
