# 目标怪物血条窗口(M17-b,E-106)

主角打中一只怪物之后,屏幕左上角出现一个窗口:头像、类别牌、"Lv 等级 名字"、一条按层着色的血条。被打掉的那一段先闪白、再变暗,然后从右往左缩短到消失;怪物死后头像上的红叉每 250 毫秒闪一次,约一秒后整个窗口消失。本文记**机制(客户端读码)、画法常量(界面布局)与我们的实现**。血条的长度要用到 PVF 里的难度表与基础属性表(原版数据),这里只记"读哪个标签、怎么算",不记具体数。

证据等级:路由、设置目标、条长公式、填充的两层画法、残影的闪光与缩短、头像与类别牌的位置、死亡叉号与隐藏规则来自静态读码(高),并且**普通窗口的静态部分、闪光公式、缩短速率、先后死亡两只怪时叉号的时间线都与基线(S07、S09)对过**;精英与首领窗口的布局来自读码,没有基线可对(中);多段残影的接续、条长公式里的"第几行"(`d`)是推断(低到中)。没有运行客户端。

## 1. 窗口对象与路由(E-106)

窗口是客户端界面管理器里的一个对象,我们用到的字段(偏移是对象内的,名字是我们自己起的):

| 偏移 | 含义 |
|---|---|
| +4 | 可见 |
| +8 | 目标(怪物对象) |
| +0xc | 怪物的"级别"整数,决定画哪种窗口 |
| +0x74 | 一层血条的宽度:构造函数 0x0043a1d0 里是 475,界面重排函数 0x00e7b920 在 0x00e7c120 经 0x004bc4f0 → 0x0043a950 改成 540;**实现取 540**(重排之后的值) |
| +0x94 | 死亡标志;+0x98 死亡计时器 |
| +0xb4 | 血条长度(像素):`min(条长, +0x74)` |
| +0xf8 | 残影(掉血历史)链表的个数 |
| +0x118 | 条长(见 §2) |

**路由 0x0043d880**(每帧):

1. 可见才往下走;有目标时,把死亡标志与"目标的当前生命是否为 0"(目标虚函数槽 +0x2a4)比较,**不同就翻转标志并重置计时器**。
2. 级别 3 或 8 画首领窗口(0x0043d490,原点 (2,96)),1 或 2 画精英窗口(0x0043d5e0,(2,96)),其余画普通窗口(0x0043d730,(4,98))。我们按 `MonsterKind` 对应:首领 → 首领窗口,两种精英 → 精英窗口,其余 → 普通窗口(**对应关系是推断**:没有核对级别整数来自哪个字段)。
3. 画完之后:死亡标志为真、计时器超过 999 毫秒、并且残影链表为空,才把可见标志清零(隐藏)。残影没播完时窗口一直在。

**设置目标 0x0043cb80**:传空 → 隐藏;与当前目标相同 → 直接返回,什么都不重置;否则换目标、记级别、置可见、算条长(§2)、把残影链表清空,显示值与"上一值"都初始化为按目标**此刻**的生命折算的填充;设置目标里也做同一段死亡标志的比较与翻转(所以上一只死了、换到另一只也已经死了,标志不变,计时器接着走)。命中处理在**伤害结算之前**调它,所以第一击就会产生残影(闪光)。

## 2. 条长与填充(E-106)

- **每层宽度** W = 540(上表)。条越长越多层:一层 540 像素,超出的用叠层表示,层颜色按 `层号 % 5` 在五种颜色间轮换(`monster_hp.img` 的第 2 到 6 帧)。
- **条长** G(辅助函数 0x0043be40):
  - 缺省(没有难度表):每层刻度 n = 300、层数 L = 100;
  - 有难度表:n = `(int)(因子 × 160.0f)`(160.0 在数据节 0x01567988),因子取 `monster/monsterapcdifficultybonus.tbl` 里 `[adjust hp gauge]` 块的 `[normal]`、`[named]`、`[boss]` 三项之一(静态缺省 1.0f 在 0x015620fc);L = 公共基础属性表(`monster/monsterbaseparameter` 里的公共那一份)第 `min(行数, d) − 1` 行的 `HpBase` 一列(表的第 6 列,偏移 +0x14);`d` 是函数 0x007ddc70 的返回值,**语义没读通,实现里用怪物等级代入(推断)**;
  - G = `(int)((float)最大生命 / (float)max(L, 1) × (float)n)`,单精度。
- **线性插值**(0x011b98c0,`Lerp(a, b, c, d)`):`c < d` 时,`c < 1` 返回 a,否则 `(int)((b − a) × c / d + a)`(单精度);`c ≥ d` 返回 b。**填充 = `Lerp(0, G, 当前生命, 最大生命)`**,所以条的长度向下取整,不是四舍五入。
- **填充函数 0x0043abc0**(x, y, 起, 止, 模式, 年龄):对一个值 v,层 = `(v − 1) / W`、层内位置 = `(v − 1) % W + 1`(C 的截断除法;v = 0 时层 0、位置 0)。只画两层:相邻两层时画低层的"起位置..W"再加高层的"0..止位置";相差两层以上时画高层 − 1 层的"止位置..W"再加高层的"0..止位置";同层时画"起..止"。画法是把 597×9 的条帧按横向区间裁切后放在条原点。
  - 模式 0:正常画。
  - 模式非 0:画**变暗**的帧(调制色 0xff969696,各通道 ×150/255);模式 1 且年龄 < 500 毫秒时,再叠一张**白色覆盖帧**(第 7 帧;首领用第 18 帧),不透明度 = `Lerp(255, 0, 年龄, 500)`。
  - 首领的条不是整帧,而是 38 像素宽的图块(第 13 到 17 帧,`层 % 5 + 13`)横向铺满,起点 `x − ((timeGetTime() / 50) % 38)`(每 50 毫秒滚动 1 像素),按区间裁切。

## 3. 三种窗口的画法(界面布局,E-106)

`monster_hp.img` 的帧(偏移全是 (0,0)):第 1 帧 626×32 普通底框;第 2 到 6 帧 597×9 条的五种颜色层;第 7 帧 597×9 白色覆盖帧;第 8 帧 3×17 普通端帽;第 9 帧 628×36 精英底框;第 10 帧 4×19 精英端帽;第 11 帧 630×36 首领底框;第 12 帧 4×36 首领端帽;第 13 到 17 帧 38×26 首领图块;第 18 帧 38×26 首领白色覆盖帧。设"条长"为 `min(G, 540)`:

| | 普通 | 精英 | 首领 |
|---|---|---|---|
| 窗口原点 | (4,98) | (2,96) | (2,96) |
| 底框 | 第 1 帧,只画前 (条长 + 29) 列 | 第 9 帧,前 (条长 + 36) 列 | 第 11 帧,前 (条长 + 33) 列 |
| 端帽 | 第 8 帧,x = 原点 x + 条长 + 29、y = 原点 y + 15 | 第 10 帧,x = 原点 x + 条长 + 36、y = 原点 y + 16 | 第 12 帧,x = 原点 x + 条长 + 33、y = 原点 y |
| 条原点 | (33,115) | (38,115) | (35,99) |
| 头像 | (6,100) | (6,100) | (6,100) |
| 类别牌起点 | (35,97) | (34,96) | (39,104) |

(条原点的 x = 窗口原点 x + 底框那一行里的固定列数(29、36、33);所以端帽正好紧贴在条的末端。)

**头像**(0x0043a310):`.mob` 的 `[face image]`(图包路径 + 帧号)指向 `sprite/monster/monsterface.img` 之类的图包里的一帧(24×24),画在上表的头像位置。目标的死亡标志为真、并且 `(计时器 / 250) & 1 == 0` 时,在头像上叠 `sprite/interface/base.img` 的第 91 帧(24×24 的红叉);也就是**死后先亮 250 毫秒、再灭 250 毫秒,如此交替**(辅助函数 0x011ba740 就是 `(经过毫秒 / 参数) & 1`)。

**类别牌与文字**(0x0043a980):对 `.mob` 的 `[category]` 里的每个名字,按客户端枚举下标(0x0129c140 把名字换成下标)查 0x01567680 处的帧表;帧号 ≥ 0 就画 `sprite/common/etc/category.img` 的那一帧,下一块的 x 右移 `1 + 帧宽`;没有帧的类别什么也不画、也不占宽。下标到帧的对应(名字 → 下标 → 帧):人型(human)0 → 0、野兽(beast)1 → 1、植物 2 → 2、昆虫 3 → 3、机械 4 → 4、混合(hybrid)6 → 5、不死 7 → 6、恶魔 8 → 7、精灵 9 → 8、龙 10 → 9、单侧移动(oneside move)19 → 10(是一帧 0×0 的空白)、人型护甲(human armor)20 → 11、堡垒护甲 21 → 12、天使 11 → 14,其余没有帧(有机体等)。文字 `"Lv%d %s"`(等级与名字)画在牌子末端 + 2、牌子那一行 + 3。

## 4. 掉血残影(E-106)

- **记录 0x0043c600**:每次更新比较"当前填充"与"上一值":变小,就把 {值 = 上一值, 时间 = 现在} 插到链表**头**,再把上一值设成当前;变大(回血),把链表里值不高于当前的节点都删掉,上一值设成当前。
- **绘制 0x0043c730**:从头(最新)开始,**年龄不到 500 毫秒的节点各画一段**:从"起"到节点的值,模式 1(变暗 + 白闪),然后起 = 节点的值(多个节点依次接着画)。遇到第一个年龄不小于 500 毫秒的节点:`顶 = 节点值 − Lerp(0, G, 年龄 − 500, min(5G, 6000))`;若 `起 < 顶`,画 [起, 顶) 模式 2(只变暗)并停下;否则把它与更老的节点都删掉。**缩短的速度是每 5 毫秒 1 像素**(跨度 = 5G 毫秒,上限 6000),与条长无关;条太长(超过 1200 像素)时才被 6000 毫秒封顶而变快。
- 多个节点的链接与"删掉更老的"这两处是按反汇编读出来的推断;基线里只出现过单个节点和"换目标清空"。

## 5. 我们的实现

- `Dnf.Game`:`HpGauge`(条长、插值、闪光不透明度、缩短、每层宽度这些常量与公式)、`HpGaugeFactors`(读 `[adjust hp gauge]`)、`MonsterDef.FaceImage`/`FaceIndex`(读 `[face image]`)、`GameData.HpGaugeFactors`。
- `Dnf.Play`:`MonsterPanelInfo`(每只怪物一份:头像、类别名、条长,创建时按 §2 算好)、`MonsterHpWindow`(窗口状态机 + 画)、`RoomCombatSession` 里接线:`Strike` 在伤害之前 `SetTarget`、每一步结束 `Update`、`AddOverlay` 里 `Build`。窗口用的图帧不在素材里时(合成测试、缺图)回落到旧的占位色块血条。
- 画法受渲染模型的限制:覆盖层精灵没有裁切与逐精灵调制色,所以条被**预先裁成横向区间的帧副本**(变暗的也预先变暗),白闪用精灵自己的不透明度。我们的 5×7 点阵字体只有 ASCII,所以文字只画 `Lv<等级>`,**怪物名字没画**(需要字体光栅,`text_cjk` 待做)。
- 命令行:`dnf combat-check`(带 `--shots-at … --png …` 看画面;开头打印"目标血条 原版样式窗口(E-106)",结尾打印窗口的最终状态)。

## 6. 与基线的对照(本机一次性测量,非 REA,不入库)

基线 S07(三段普通攻击)与 S09(一路打到怪物死亡)的逐帧截图:

- **静态部分**:底框、端帽、头像、类别牌、血条填充段,与我们的画法对照,**不透明像素逐个一致**。
- **闪光公式**:被打掉那一段的像素对"变暗帧 + 白色覆盖帧 × α"拟合,整段像素落在同一个 α 上;随后每 100 毫秒 α 降约 51(= 255 × 100 / 500),与 `Lerp(255, 0, 年龄, 500)` 一致;第一击的那一帧 α 对应年龄约 50 毫秒。
- **缩短**:闪光结束后,残影的右端每 100 毫秒向左缩约 20 像素(= 每 5 毫秒 1 像素),缩到填充处就消失。
- **换目标**:S09 里先后被打死的两只同类怪,第二只出现的那一帧,第一只的残影立刻没有(设置目标清空历史)。
- **死亡与隐藏**:S09 的叉号序列(亮 4 帧、灭 2 帧、亮 3 帧、灭 2 帧、窗口消失)能用"250 毫秒亮灭、第二只怪死亡时计时器重新开始、之后 1000 毫秒隐藏"的模型逐帧解释;第一只与第二只的死亡时间也与各自残影闪光的年龄对得上。

## 7. 没读通 / 没做

- `d`(条长公式里取基础表第几行)的来源函数 0x007ddc70 没读通;实现里用怪物等级代入,等级大于表的行数时取最后一行。**不同怪物的条长因此可能与原版差几个像素**,基线只对过一种怪物的普通窗口。
- 怪物打主角时窗口会不会也设置目标(例如显示"正在打你的怪物"),没读到;只做了主角打怪物。
- 精英与首领窗口(含首领图块的滚动、首领的闪光覆盖帧)按读码做了,没有基线可以对。
- 多个残影节点的链接与"删掉更老的"(§4)只有读码,没有基线。
- 怪物**名字**:要字体光栅(CJK),没做;目前只有 `Lv<等级>`。
- 空白类别帧(帧宽 0、画布 1×1)占的宽度到底按帧宽还是画布宽,基线里没有对应的怪物,按帧宽(0)处理。
- 头像下标越界或缺图时原版的行为没看,我们是不画头像。
