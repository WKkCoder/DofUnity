# 右上角副本小地图(M17-e,E-109)

进入副本后,屏幕右上角吸附一块半透明的迷宫小地图窗口:外围是 9 宫格边框,第一行是顶栏标题条,下面是迷宫各格的房间通道瓦片;当前房间高亮并叠人物小图标,首领房间叠骷髅图标,当前房间清空后与之通过打开的门相连的邻格按 250 毫秒半周期闪烁(已去过的邻格在常态与高亮通道之间闪,未去过的邻格在常态与高亮问号格之间闪)。本文记录客户端的构造、初始化、网格布局、瓦片编号、闪烁与图标规则,以及与基线截图的逐像素核对结果。

证据等级:窗口类构造与虚表、网格尺寸与右上角吸附坐标、9 宫格边框与顶栏绘制、房间瓦片公式与变体随机数、可见性与闪烁条件、人物标与首领骷髅标偏移来自客户端静态读码(高);窗口边框、顶栏、6 个房间的通道瓦片(含非零随机变体)、问号格、人物标与首领骷髅标与基线 S07/S09/S10 逐像素 100% 吻合(高)。静态读码用 Ghidra 只读脚本与本机反汇编脚本,基线像素比对用本机一次性 PIL 脚本,均为**非 REA**。

## 1. 客户端窗口类与两套图包(E-109)

- **构造与注册**:界面装配函数 `0x00f139a0`(在 `0x00f15510` 与 `0x00f16995` 两处分支)分配 `0x23c` 字节,传入脚本路径 `"UI/DungeonMinimap/DungeonMinimap.ui"`,调构造函数 `0x010383c0` 装入虚表 `0x0182c8a4`(主虚表)/ `0x0182c89c`:
  - 虚表 `+0x00` = `0x01038690`:小地图主绘制函数;
  - 虚表 `+0x14` = `0x010384e0`:初始化函数,调 `0x01069070` 应用 `.ui` 窗口属性、调 `0x010381d0` 按迷宫宽高调整窗口尺寸,并装载窗口图包到 `this + 0x234`;
  - 虚表 `+0x44` = `0x00ef95a0`:通用网格窗口尺寸重算(`tileSize = 18`,四周 8 像素边框)。
- **两套图包**:
  1. **窗口与图标图包(`*(this + 0x234)`)**:`sprite/interface2/minimap/dungeon/minimap.img`(共 203 帧):
     - `#3`(6×12):当前房间人物小图标,画在 `(cellX + 6, cellY + 4)`(`0x01038d53`..`0x01038d69`);
     - `#27..#35`(`0x1b`,在 `0x01038944` 写入 `this + 0x6c`,由 `0x00ef7e20` → `0x00ef6a50` 的 `tileType == 10` 分支绘制):窗口 9 宫格边框与中心半透明底(`#27` 左上 5×5 偏移 (3,3) 画布 8×8、`#28` 上边 18×5 偏移 (0,3) 画布 18×8、`#29` 右上 4×5 偏移 (0,3) 画布 8×8、`#30` 左边 5×18 偏移 (3,0) 画布 8×18、`#31` 中心底块 18×18 alpha=128、`#32` 右边 4×18 画布 8×18、`#33` 左下 5×4 偏移 (3,0) 画布 8×8、`#34` 下边 18×4 画布 18×8、`#35` 右下 4×4 画布 8×8);
     - `#37`(`0x25`,16×14):首领骷髅图标,由 `0x010382b0` 画在 `(cellX + 1, cellY + 2)`(`0x0103839a`..`0x010383ae`);
     - `#39`(`0x27`,18×18,alpha=224):顶栏标题条瓦片(`*(this + 0x70)`),在 `0x00ef7a26`..`0x00ef7aba` 沿内框第 0 行横向平铺;
     - `#44..#165`:额外的通道覆盖层帧,在单人普通副本里(`0x01038ca0`)透明度因子被置 0(`alpha = (int)(0 * 2.25f) = 0`,常数 `2.25f` 在 `0x015ac080`),实际不显示。
  2. **副本房间瓦片图包(`*(dungeon + 0xc0)`)**:由副本定义 `.dgn` 的 `[minimap image]` 标签在 `0x012fe559` 冠上 `"sprite/"` 装载(全库 346 个 `.dgn` 中 342 个含此标签,如 `sprite/map/minimap/act1.img`、`act2.img`、`act3.img`、`act6.img`、`helixlab.img`),共 122 帧 18×18。

## 2. 窗口网格尺寸与右上角吸附位置

- **网格行列数(`0x010381d0`、`0x0103886e`..`0x010388af`)**:
  - 显示列数 `displayCols = max(cols, 3)`:迷宫列数不足 3 列时窗口仍按 3 列宽显示;
  - 显示行数 `displayRows = rows + 1`:内框第 0 行是 18 像素高的顶栏标题条(`#39`),第 `1..rows` 行是迷宫各行;
  - 窄迷宫的列偏移(`0x01038a6b`..`0x01038a82`):当 `cols < 3` 时,迷宫第 `x` 列向右偏 1 列画在 `displayCol = x + 1`,第 0 显示列只铺 `#31` 底块、留空不画房间。
- **右上角吸附坐标(`0x0103cf30`、`0x01038721`..`0x0103873f`)**:
  - 吸附在右上角时,内框宽度 `windowWidth = displayCols * 18`,内框左上角固定在:
    - `windowX = 793 - displayCols * 18`(`0x319 - windowWidth`;当 `displayCols = 3` 时 `windowX = 739`);
    - `windowY = 29`(`0x1d`);
  - 外围 8 像素的 9 宫格边框包住内框 `[windowX, windowX + displayCols * 18) × [windowY, windowY + displayRows * 18)`:
    - 上边框行 `y = windowY - 8 = 21`:左角 `#27` 在 `windowX - 8`,上边 `#28` 在 `windowX + c * 18`,右角 `#29` 在 `windowX + displayCols * 18`;
    - 内框各行 `ry = windowY + r * 18`(`r = 0..displayRows - 1`):左边 `#30` 在 `windowX - 8`,中心底 `#31` 在 `windowX + c * 18`,右边 `#32` 在 `windowX + displayCols * 18`;
    - 下边框行 `y = windowY + displayRows * 18`:左下 `#33`、下边 `#34`、右下 `#35`;
  - 迷宫格 `(x, y)` 的屏幕左上角:
    - `cellX = windowX + DisplayCol(cols, x) * 18`
    - `cellY = 29 + (y + 1) * 18 = 47 + y * 18`。

## 3. 房间瓦片编号与随机变体(`0x004ba760`、`0x01038bc2`..`0x01038c0d`)

- **瓦片编号函数 `0x004ba760(exitMask, seed, highlighted)`**:
  - 副本迷宫的四个出口位掩码 `exitMask ∈ [1, 15]`(`Right = 1, Up = 2, Left = 4, Down = 8`)在 `act*.img` 的前 120 帧(`#0..#119`)中按顺序每一种占 8 帧:
    - 前 4 帧(`+0..+3`)是常态通道瓦片;
    - 后 4 帧(`+4..+7`)是高亮通道瓦片(用于当前房间以及闪烁时的已探索邻格);
    - 公式:`frame = (exitMask - 1) * 8 + (highlighted ? 4 : 0) + variant`(`variant ∈ 0..3`)。
  - 当 `exitMask == 0`(未知邻格或首领格底块)或超出 `1..15` 时,返回 `120 + (highlighted ? 1 : 0)`:`#120`(`0x78`)为常态问号格,`#121`(`0x79`)为高亮问号格。
- **变体随机数(`0x01038bc2`..`0x01038c07`)**:
  - 已访问房间对象在 `+0x248` 处存放其 `.map` 的地图编号(`map.lst` 编号,在 `0x007dc770` 写入,与 `E-074` 过门落点随机种子用的是同一个字段);
  - 种子 `seed = (uint)(mapId * y * x)`,调客户端三步线性同余随机数 `0x00e50e60`(`ClientRandom.Next(ref seed)`)取模 4 得 `variant = r & 3`;
  - 当 `x == 0` 或 `y == 0` 时 `seed == 0`,三步推进后的低 2 位恒为 `0`,故第 0 列与第 0 行的房间恒取 `variant = 0`;非零行列(`x > 0 && y > 0`)由 `mapId * y * x` 决定确定的外观变体。

## 4. 房间显示状态、开门邻格闪烁与图标(`0x01038a15`..`0x010391c8`)

- **闪烁开关与周期(`0x01038a15`..`0x01038a64`)**:
  - 当当前房间已经清空且当前房间不是首领格时,`canBlink = true`;
  - 闪烁相位按客户端时钟每 250 毫秒翻转一次:`blinkOn = (~(clockMs / 250) & 1) != 0`(`0..249` 毫秒为亮,`250..499` 毫秒为灭)。
- **开门邻格判定(`0x007d6e30` + `0x007d6a50`)**:
  - 检查目标格 `(x, y)` 是否是当前格 `(curX, curY)` 的四邻格(`curX - 1` 左、`curX + 1` 右、`curY - 1` 上、`curY + 1` 下),且当前房间对应方向的门在已打开掩码(`*(byte *)(room + 0x5a4)`)中置位。
- **每格 `(x, y)`(`exitMask != 0`)的绘制分支**:
  1. **当前房间(`x == curX && y == curY`,`0x01038b7f`..`0x01038d7e`)**:
     - 画高亮通道瓦片 `(exitMask - 1) * 8 + 4 + variant`;
     - 在 `(cellX + 6, cellY + 4)` 画 `minimap.img #3`(6×12 人物图标);
     - 若当前房间本身是首领格,`0x010391a2`..`0x010391b6` 跳过 `0x010382b0`,不叠首领骷髅标。
  2. **非当前房间的首领格(`isBossCell(x, y) && (x != curX || y != curY)`,`0x01038d8c`、`0x0103903a`、`0x01039188`..`0x010391c8`)**:
     - 无论是否去过或是否与当前格相邻,始终调 `0x010382b0`:先画 `act*.img #120` 问号底块,再在 `(cellX + 1, cellY + 2)` 画 `minimap.img #37`(16×14 首领骷髅标),且不随清房闪烁。
  3. **已访问过的普通房间(`visitedRoom != null && !isBossCell`,`0x01038d83`..`0x0103902c`)**:
     - `highlighted = canBlink && blinkOn && isOpenGateNeighbour`;
     - 画 `(exitMask - 1) * 8 + (highlighted ? 4 : 0) + variant`。
  4. **未访问过的普通房间(`visitedRoom == null && !isBossCell`,`0x01039031`..`0x01039188`)**:
     - 仅当 `canBlink && isOpenGateNeighbour`(当前房间已清空、非首领且通过打开的门与该格相连)时,调 `0x004ba760(0, 0, blinkOn)` 画 `#120`(灭相位)/ `#121`(亮相位)闪烁问号格;
     - 当前房间尚未清空、或与当前房间不直接连通的未访问普通格不画任何瓦片(只露窗口 `#31` 底块)。

## 5. 与基线截图逐像素核对(非 REA)

拿本机已有的基线截图 `S07-approach-1.png`、`S09-before.png`、`S10-back-to-room1.png`、`S10-room2-fight1.png`、`S10-room2-east.png`、`S10-room3-fight1.png`、`S10-room4-fight1.png`、`S10-room5-fight1.png` 与我们渲染的画面逐像素比对:

- **窗口位置与边框**:2 列 × 3 行迷宫按 3 列 × 4 行显示,内框左上角 `(739, 29)`,外框 `#27..#35` 与第 0 行顶栏 `#39` 的全部不透明像素 100% 吻合;
- **全部 6 个房间的通道瓦片与随机变体**:
  - `格 (0,0)`(显示列 1,行 0,`(757, 47)`):`exit = 9, variant = 0` → 常态 `#64` / 高亮 `#68`,不透明像素 100% 吻合;
  - `格 (1,0)`(显示列 2,行 0,`(775, 47)`):`exit = 4, variant = 0` → 常态 `#24` / 高亮 `#28`,不透明像素 100% 吻合;
  - `格 (0,1)`(显示列 1,行 1,`(757, 65)`):`exit = 11, variant = 0` → 常态 `#80` / 高亮 `#84`(清完第一房后未进过时闪 `#121` 问号格,196/196 像素 100% 吻合);
  - `格 (1,1)`(显示列 2,行 1,`(775, 65)`):`exit = 12`,由 `seed = mapId * 1 * 1` 算出 `variant = 3` → 常态 `#91` / 高亮 `#95`,与基线 `S10-room4`/`S10-room5` 196/196 像素 100% 吻合;
  - `格 (0,2)`(显示列 1,行 2,`(757, 83)`,首领格):未进入时始终画 `#120` + `#37` 首领骷髅标(`(758, 85)` 处 145/145 不透明像素 100% 吻合);
  - `格 (1,2)`(显示列 2,行 2,`(775, 83)`):`exit = 6`,由 `seed = mapId * 2 * 1` 算出 `variant = 2` → 高亮 `#46`,与基线 `S10-room5` 不透明像素 100% 吻合;
- **人物标 `#3`**:在当前格 `(cellX + 6, cellY + 4)` 处 42/42 不透明像素 100% 吻合。
